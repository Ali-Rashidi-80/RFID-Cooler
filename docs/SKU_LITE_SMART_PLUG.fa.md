# SKU Lite — پریز / رلهٔ بازار فقط برای تغذیهٔ کل

**زبان‌ها:** [English](SKU_LITE_SMART_PLUG.md) · **فارسی**

## قانون ایمنی

**هرگز** پریز هوشمند یا رلهٔ تک‌کانال خانگی را به‌عنوان کنترل Off / Slow / Fast موتور کولر سیم‌کشی نکنید.

بار القایی + جریان هجومی استارت می‌تواند کنتاکت را بچسباند یا آتش‌سوزی ایجاد کند. کنترل سرعت فقط از هستهٔ RFID-Cooler (SSR + رلهٔ مکانیکی dry-switch) انجام شود.

## کاربرد مجاز

```
[برق شهر] → [پریز/رله بازار] → [کنتاکتور مناسب آمپر] → [کل تغذیهٔ برد/کولر]
                              ↘ RFID-Cooler همچنان Off/Slow/Fast را مدیریت می‌کند
```

- پریز = فقط **قطع/وصل تغذیهٔ کل** وقتی دستگاه باید کاملاً بی‌برق شود.
- ریموت ۴۳۳ بازار برای **سه حالت سرعت** را روی خود کنترلر با `rf433_enabled` لرن کنید (نه روی پریز).

## توصیه بازار ایران

| نیاز | راه درست |
|------|----------|
| ریموت فیزیکی ساده | RF433 learn روی ESP32 |
| کنترل از راه دور اینترنت | Cloud WSS / Melipayamak هشدار |
| قطع اضطراری تغذیه | پریز/کنتاکتور SKU Lite |
